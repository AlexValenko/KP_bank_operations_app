# Приложение для анализа банковских операций


## Краткое описание

Данный проект предоставляет возможность работы с выгрузкой банковских операций в формате xlsx. Имеются инструменты статистического анализа банковских операций по категориям, 
выборки по датам и другой функционал. Приложение предоставляет возможность подгружать актуальные курсы валют и стоимости акций, заданных в файле пользовательских настроек.
Проект выполнен в IDE PyCharm с использованием Poetry. Зависимости прописаны в toml-файле. Имеется логирование основных модулей, отчеты сохраняются в директорию /data/<br>

## Основная функция
Основная функция задана в модуле main.py в корне проекта. При запуске main.py выполняет основные функции программы - 
считывает данные из файла XLSX, выгружает данные для Веб-страницы 'Главная', формирует из них json-строку,
 выполняет функции из модулей "Сервисы" и "Отчеты", сохраняет результаты в переменные.<br> 

## Примеры использования
Загрузите собственный файл operations.xlsx в папку data/. Файл должен иметь набор обязательный набор полей.<br>
Для корректной работы всех функций необходимо Интернет-подключение.<br>
Проверьте содержимое файла user_settings.json - в нем должны содержаться коды запрашиваемых валют и список акций.
Запустите main.py, в результате будет получено:<br>
*main_page_data* - переменная, содержащая json-строку с приветствием, информацией из .xlsx по каждой карте,
А также курсы валют и стоимость выбранных акций (по user_settings.json).<br>
*cashback_by_categories* - переменная, содержащая json-строку - сумма возможного кэшбека по категориям в выбранный месяц.<br>
*investments* - переменная, содержащая сумму, которую удалось бы отложить в «Инвесткопилку» в выбранный месяц <br>
*current_category_spending* - переменная, содержащая DataFrame библиотеки pandas, содержащая траты по заданной категории за последние три месяца.
Результат также записывается в файл data/spending_by_category_report.json при помощи декоратора.<br>
*weekdays_spending* - переменная, содержащая DataFrame библиотеки pandas, содержащая средние траты в каждый из дней недели за последние три месяца.
Результат также записывается в файл data/default_reports.json при помощи декоратора<br>


### Описание функций
Основные функции реализованы в модулях пакета src/: views.py, services.py, reports.py<br>
**Модуль views<br>**
Основная функция get_main_page_data - для получения данных для главной страницы, принимает на вход дату в строковом формате YYYY-MM-DD HH:MM:SS 
и возвращает JSON-ответ со следующими данными: Приветствие в формате «Доброе утро» / «Добрый день» в зависимости от текущего времени.<br>
По каждой карте: <br>
- последние 4 цифры карты;
- общая сумма расходов;
- кешбэк (1 рубль на каждые 100 рублей).
- Топ-5 транзакций по сумме платежа.

Курс заданных в пользовательских настройках валют из exchangerate-api.<br>
Стоимость заданных в пользовательских настройках акций из Мосбиржи.<br>
Функция упаковывает данные в JSON строку<br>

**Модуль services<br>**
Функция **get_cashback_categories** - Принимает на вход данные для анализа из файла operations.xlsx, год и месяц.<br>
Входные параметры:
- data — данные с транзакциями объектом DataFrame pandas;<br>
- year — год, за который проводится анализ;<br>
- month — месяц, за который проводится анализ. 

На выходе — JSON с анализом, сколько на каждой категории можно заработать кешбэка в указанном месяце года.<br>
Кэшбек расчитывается как 1% от суммы успешно проведенной операции (оплаты), исключая категории:<br>
['Пополнения', 'Переводы', 'Финансы', 'Проценты', 'Бонусы', 'Наличные']. Данные отсортированы по убыванию по возможной сумме кэшбека.<br>

Функция **investment_bank** - Принимает на вход три аргумента:<br>
- month — месяц, для которого рассчитывается отложенная сумма (строка в формате 'YYYY-MM').<br>
- transactions — DataFrame pandas с банковскими операциями.<br>
- limit — предел, до которого нужно округлять суммы операций (целое число), по умолчанию - 50 руб.

Возвращает сумму, которую удалось бы отложить в «Инвесткопилку» (число float)<br>

**Модуль reports<br>**
Функция **spending_by_category** - Принимает на вход:<br>
- transactions — DataFrame pandas с банковскими операциями.<br>
- Категорию операций (строка)<br>
- Дату в формате dd-mm-YYYY (необязательный, по умолчанию берется текущая дата).

Функция возвращает траты по заданной категории за последние три месяца<br>
Результат также сохраняется в файл json, имя которого задается параметром декоратора write_down_report_select_file.<br>

Функция **spending_by_weekday** - принимает на вход:<br>
- transactions — DataFrame pandas с банковскими операциями.<br>
- опциональную дату (Если дата не передана, то берется текущая дата)

Функция возвращает средние траты в каждый из дней недели за последние три месяца от переданной даты.
Результат также сохраняется в файл data/default_reports.json, при помощи декоратора write_down_report_default.<br>

**Вспомогательные модули<br>**
Модуль **src/utils**<br>
В модуле реализованы функции для работы с DataFrame pandas для считывания финансовых операций из файла Excel, включая первичную валидацию данных на соответствие столбцов исходной таблицы.<br>
Имеются функции по формированию списка карт пользователя, фильтрации данных по дате, формированию топ-5 операций и иные функции по фильтрации и агрегации данных.<br>
Модуль **src/external_api**<br>
Модуль реализует функции по чтению настроек пользователя из файла user_settings.json.
Реализованы функции по получению актуальных курсов валют и стоимости акций по api. Актуальные курсы валют сохраняются в кэш. Если дата кэш-файла совпадает с текущей датой, курсы валют берутся из него.

## Документация и ссылки
Код оформлен по PEP8 c автоматическими форматерами black и isort, проверен flake8.<br>
По результатам тестирования pytest-cov имеется отчет в директории /htmlcov. Покрытие тестами 85 %.<br>
В директории logs содержатся log-файлы по результату единовременного выполнения функций. Файл перезаписывается.<br>
В программе обработаны основные ошибки при работе с файлами, api-запросами, преобразованием дат. Отсутствие данных api не останавливает программу, а возвращает пустые наборы (списки).<br>
