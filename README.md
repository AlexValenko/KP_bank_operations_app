# Приложение для анализа банковских операций


## Краткое описание

Данный проект предоставляет возможность работы с выгрузкой банковских операций в формате xlsx. Имеются инструменты статистического анализа банковских операций по категориям, выборки по датам и другой функционал. Приложение предоставляет возможность подгружать актуальные курсы валют и стоимости акций, заданных в файле пользовательских настроек.
Проект выполнен в IDE PyCharm с использованием Poetry. Зависимости прописаны в toml-файле.<br>



## Установка и использование
### Требования:
Python 3.14<br>
Poetry 2.3.2
### Установка проекта
Клонируйте репозиторий<br>

Установите poetry<br>
pip install poetry<br>
Установите зависимости<br>
poetry install

### Зависимости
В проекте используются следующие зависимости.<br>
*requests (>=2.33.1,<3.0.0)* - для работы с HTTP запросами <br>
*python-dotenv (>=1.2.2,<2.0.0)* - для работы с файлами переменного окружения <br>
*types-requests (>=2.33.0.20260513,<3.0.0.0)* - для типизации библиотеки requests <br>
*pandas (>=3.0.3,<4.0.0) и openpyxl (>=3.1.5,<4.0.0)* - для обработки табличных данных их xlsx <br>
Все необходимые настройки находятся в pyproject.toml.<br><br>
Для разработки используются инструменты:<br>
flake8 — проверка стиля кода<br>
black — автоформатирование кода<br>
isort — сортировка импортов<br>
mypy — статическая типизация<br>
pandas-stubs - для типизации объектов библиотеки pandas<br>
Для тестирования применен фрэймворк pytest:<br>
Для оценки покрытия тестами использована библиотека pytest-cov:<br>
